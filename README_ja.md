# HATENKO × inimu

職業訓練の制作実習として制作した架空のWebサイトです。破天荒およびinimuの公式サイトではなく、実在する企業・店舗とは関係ありません。掲載している香水体験・予約サービスは実際には提供していません。

## 構成

10ブロックで構成しています。

1. ヒーロー
2. 体験の流れ
3. 香水ギャラリー2種
4. 聞き重ね
5. 散策3コース
6. 料金
7. アクセス
8. FAQ
9. 最終CTA
10. フッター

香りの名称は破天荒の公式コレクションに準拠し、公式ロゴ・商品画像は元画像を改変せずに使用しています。

外部リンク先は未設定です。予約ボタンは実習用デモのモーダルを表示し、実際の予約は受け付けません。

## 開き方

`index.html` をブラウザーで開いてください。PCとスマートフォンの画面幅に対応しています。

## ファイル

- `index.html` — ページとモーダルの構造
- `style.css` — 表示スタイル
- `script.js` — メニュー、FAQ、モーダル、ギャラリーの操作
- `assets/` — 画像や背景素材
