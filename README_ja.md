# HATENKO × inimu — LPレイアウト確認用

## 状態
Figma StarterプランのMCP操作上限により、Figmaファイルに直接反映できなかったため作成した **ローカルの代替レイアウト見本** です。Figmaの変更は行っていません。

## 開き方
`index.html` をChrome等で開いてください。ブラウザ幅を変更すると、PC版（1440px想定）・スマホ版（390px想定）の切り替えが確認できます。

## 反映したレイアウト
- PCの本文幅1100px、セクション間隔120px。スマホ左右24px、セクション間隔80px。
- 10ブロック（ヒーロー／3ステップ／香水2ギャラリー／聞き重ね／3つの散策カード／料金／アクセス／FAQ／最終CTA／フッター）を構成。
- 香水2ギャラリーは横スクロール配置。写真とカードの実素材は一部未配置。
- 散策カードはPC3枚並列／スマホ横スワイプ、詳細はPC地図60％＋解説40％／スマホ全画面。
- 料金／最終CTA／フッターは同じ墨色和紙素材。FAQは5項目、初期閉じ。
- 公式ロゴ2枚・公式商品画像10枚は入手済みの元画像を改変せず使用（CSSによる暗色背景対応の視覚効果のみ）。

## あえて未実施にしたこと
- Figmaのノード変更・更新。
- 雷門ヒーロー、浅草の実写写真3点、地図画像の確定と配置。現時点では写真枠や地図の仮表示。
- 公式の香り名・ギャラリー所属の確定、歴史の裏取り、店舗詳細、じゃらんURLの設定。
- 写真・コピーや公式素材の差し替えを伴う最終仕上げ。
- 印刷用観光マップの制作。今回の対象はLPのレイアウトのみです。

## レイアウト確認の注意
香水カードの仮番号「作品 01〜10」、一部の説明文、写真・地図の表示は **レイアウト検証用** です。公式の作品分類や店舗情報として利用しないでください。

## ファイル
- `index.html` — LPとモーダルの構造
- `style.css` — PC / モバイルのレイアウト
- `script.js` — メニュー、FAQ、モーダル、ギャラリー操作確認用
- `assets/` — 提供画像の複製（改変なし）、和紙背景
- `screenshots/` — 確認用キャプチャ（作成済みの場合）
